
# 第14章 自测题库

## 一、单选题（每题5分，共30分）

### 1. MCP协议的全称是什么？
A. Model Control Protocol  
B. Model Context Protocol  
C. Modern Communication Protocol  
D. Multi-Context Protocol  

✅ **答案：B**  
**解析：** MCP的全称是Model Context Protocol（模型上下文协议），是由Anthropic提出的开放协议。

---

### 2. MCP协议的三大核心能力不包括以下哪一项？
A. 工具（Tools）  
B. 资源（Resources）  
C. 提示模板（Prompts）  
D. 模型训练（Training）  

✅ **答案：D**  
**解析：** MCP的三大核心能力是工具（Tools）、资源（Resources）和提示模板（Prompts），不包括模型训练。

---

### 3. MCP协议使用什么作为基础通信协议？
A. REST API  
B. GraphQL  
C. JSON-RPC 2.0  
D. gRPC  

✅ **答案：C**  
**解析：** MCP使用JSON-RPC 2.0作为基础协议，所有消息都是JSON格式。

---

### 4. 以下哪种是MCP协议最简单的传输方式？
A. HTTP  
B. WebSocket  
C. stdio（标准输入输出）  
D. TCP Socket  

✅ **答案：C**  
**解析：** stdio（标准输入输出）是MCP最简单的传输方式，适用于本地进程间通信。

---

### 5. 在MCP协议中，用于列出可用工具的方法是？
A. tools/get  
B. tools/list  
C. tools/call  
D. tools/register  

✅ **答案：B**  
**解析：** `tools/list` 方法用于列出MCP服务器提供的所有可用工具。

---

### 6. MCP协议中的资源（Resources）主要用于提供什么？
A. 可执行函数  
B. 数据源  
C. 提示词模板  
D. 训练数据  

✅ **答案：B**  
**解析：** 资源（Resources）是MCP服务器提供的数据源，可以是文件、数据库记录、API响应等。

## 二、多选题（每题8分，共32分）

### 7. MCP协议解决了以下哪些问题？（多选）
A. 工具和资源的标准化访问  
B. 安全性和权限控制  
C. 上下文管理  
D. 生态系统互操作性  

✅ **答案：A、B、C、D**  
**解析：** MCP协议主要解决：工具和资源的标准化访问、安全性和权限控制、上下文管理、生态系统互操作性等问题。

---

### 8. MCP协议的架构包含哪些核心组件？（多选）
A. MCP客户端（Client）  
B. MCP服务器（Server）  
C. 传输层（Transport）  
D. 模型层（Model）  

✅ **答案：A、B、C**  
**解析：** MCP协议采用客户端-服务器架构，包含MCP客户端、MCP服务器和传输层三个核心组件。

---

### 9. 在MCP协议中，以下哪些是有效的传输方式？（多选）
A. stdio（标准输入输出）  
B. Streamable HTTP  
C. WebSocket  
D. UDP  

✅ **答案：A、B**  
**解析：** MCP协议支持stdio和Streamable HTTP等传输方式，WebSocket和UDP不是标准的MCP传输方式。

---

### 10. 关于MCP协议与其他技术的区别，以下说法正确的是？（多选）
A. MCP提供标准化接口，而传统工具调用多为自定义实现  
B. MCP具有内置的安全机制  
C. MCP支持自动发现功能  
D. MCP原生支持资源访问  

✅ **答案：A、B、C、D**  
**解析：** 这些都是MCP协议相比其他技术的优势：高度标准化、内置安全机制、自动发现能力、原生资源支持等。

## 四、简答题（每题9分，共18分）

### 16. 请简述MCP协议的主要特点和应用场景。

✅ **答案要点：**  
主要特点：
1. **标准化接口**：提供统一的工具和资源访问规范
2. **三大核心能力**：工具（Tools）、资源（Resources）、提示模板（Prompts）
3. **多种传输方式**：支持stdio、HTTP等传输方式
4. **安全机制**：内置权限控制和审计能力
5. **开放生态**：促进不同系统间的互操作性

应用场景：
1. AI助手与外部工具集成
2. 企业内部系统的AI接入
3. 开发可扩展的AI应用
4. 构建安全的AI工具生态系统

---

### 17. 请描述如何在LangChain中集成MCP协议，包括主要步骤和注意事项。

✅ **答案要点：**  
主要步骤：
1. **创建MCP服务器**：实现包含所需工具和资源的MCP服务器
2. **创建MCP客户端**：编写客户端代码连接到MCP服务器
3. **工具包装**：将MCP工具包装为LangChain的BaseTool子类
4. **Agent创建**：使用LangChain的Agent框架，集成MCP工具
5. **测试运行**：验证集成效果，进行必要的调整

注意事项：
1. **异步处理**：MCP客户端通常是异步的，需要正确处理异步调用
2. **错误处理**：实现健壮的错误处理机制
3. **资源管理**：正确管理连接和资源，避免泄漏
4. **安全性**：实施适当的权限控制和输入验证
5. **性能优化**：考虑缓存、并发等性能优化策略
