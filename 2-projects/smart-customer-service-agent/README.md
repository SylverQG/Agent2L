# Smart Customer Service Agent (智能客服 Agent)

基于 LangChain + OpenAI 的智能客服对话系统，能够理解客户意图、搜索知识库、查询订单状态和创建工单。

## 功能特性

- **意图识别**：自动从自然语言中识别客户意图
- **知识库搜索**：从内置知识库检索相关答案（支持退换货政策、密码重置等常见问题）
- **订单状态查询**：根据订单号查询物流和订单状态
- **工单创建**：记录客户姓名和问题描述，生成唯一工单号
- **ReAct 推理循环**：实现推理-行动循环，智能编排多工具调用

## 环境配置

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 在项目根目录创建 `.env` 文件：

```env
OPENAI_API_KEY=你的OpenAI密钥
```

3. 运行智能客服：

```bash
python main.py
```

## 使用示例

启动后可直接与客服对话：

- "你们的退货政策是什么？"
- "我想查询订单 ORD-20240501 的状态"
- "我的快递有问题，我叫张三，需要创建一个工单"
- "我忘记密码了，怎么重置？"

输入 `exit` 或 `quit` 退出对话。

## 技术架构

该 Agent 使用 ReAct 模式（推理 + 行动），流程如下：

1. 用户输入问题
2. LLM 分析意图，决定调用哪个工具
3. 执行工具调用（搜索知识库/查询订单/创建工单）
4. 工具结果返回给 LLM 生成自然语言回答
5. 进入下一轮对话
